Святое Торжище
Ссылка: (https://krivetochkin.github.io/RKVP/)
Святое Торжище — это специализированный интернет-магазин, предлагающий широкий ассортимент православной продукции для верующих и интересующихся культурой. Платформа предназначена для удобного поиска и приобретения икон, духовной литературы, церковной утвари и подарков с религиозным смыслом. Мы стремимся сделать православные товары доступными для покупателей по всей стране, обеспечивая качественный сервис и достоверность информации о каждом изделии. Сайт также служит просветительским ресурсом, помогая пользователям правильно ориентироваться в выборе церковных принадлежностей.
Целевая аудитория
Практикующие православные христианы, желающие приобрести товары для личной молитвы и церковного быта.
Люди, подбирающие тематические подарки к религиозным праздникам (Пасха, Рождество, Крещение, именины).
Интересующиеся православной культурой, историей церкви и духовной литературой, включая студентов и исследователей.
Ключевой функционал
Каталог товаров: Удобная навигация по категориям (иконы, книги, свечи, одежда, утварь) с фильтрами по цене, размеру, материалу и назначению.
Корзина и оформление заказа: Безопасная оплата онлайн, выбор способа доставки и отслеживание статуса заказа в личном кабинете.
Личный профиль пользователя: История покупок, сохранение избранных товаров в «Отложенное» и управление адресами доставки.
Кнопка «Поставить свечу онлайн»: Пользователь сможет зажечь виртуальную свечу.
Генератор имен для крещения: Если родители не могут определиться, то генератор поможет выбрать имя святого из календаря на текущую дату.

## Локальный запуск

### Требования

- Node.js 18+
- Проект Supabase (PostgreSQL) с выполненными миграциями из `Backend/migration.sql` и дополнительных файлов `migration-*.sql`

### 1. Бэкенд

```bash
cd Backend
cp .env.example .env
npm install
npm run dev
```

Сервер по умолчанию: `http://localhost:3000`

Проверка: `GET http://localhost:3000/api/health`

### 2. Фронтенд

```bash
cd Frontend/orthodox-store
npm install
# Опционально: .env с VITE_API_URL=http://localhost:3000/api
npm run dev
```

Сайт по умолчанию: `http://localhost:5173`

## Переменные окружения

### Backend (`Backend/.env`)

| Переменная | Описание |
|------------|----------|
| `PORT` | Порт сервера (по умолчанию 3000) |
| `SUPABASE_URL` | URL проекта Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | Service role key |
| `JWT_SECRET` | Секрет для JWT (≥ 32 символа) |
| `ADMIN_EMAILS` | Email админов через запятую |
| `SELLER_EMAILS` | Email продавцов через запятую |
| `DATABASE_URL` | URI PostgreSQL (для `npm run migrate:cart`) |

### Frontend

| Переменная | Описание |
|------------|----------|
| `VITE_API_URL` | Базовый URL API, например `https://api.example.com/api` |

## Основные функции

- **Каталог** — поиск, фильтр по категории и цене, сортировка, пагинация («Загрузить ещё»), избранное
- **Корзина** — гостевая и серверная для авторизованных пользователей, оформление заказа
- **Личный кабинет** — профиль, заказы, избранное, выход из аккаунта
- **Аутентификация** — регистрация, вход, сброс пароля (email или ключевое слово), защита маршрутов
- **Виртуальная свеча** — счётчик посетителей за день
- **Генератор имён** — имена святых по дате и полу
- **Панель продавца/админа** — CRUD товаров, управление ролями (admin)

| GET | `/api/health` | Проверка БД |

| POST | `/api/auth/forgot-password` | Запрос ссылки на email |

| GET/POST/PATCH/DELETE | `/api/cart` | Корзина (авторизация) |
| GET/POST | `/api/favorites` | Избранное |
| GET/POST | `/api/orders` | Заказы |
| GET/POST | `/api/candles` | Виртуальная свеча |
| GET | `/api/names` | Имена святых |
| GET/POST | `/api/admin/users` | Пользователи (admin) |
